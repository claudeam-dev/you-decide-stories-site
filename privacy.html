Who we are

You Decide Stories is a personal YouTube channel and a small automation tool run by a single owner. This policy explains how the tool uses Google user data.

What data the tool accesses

The tool is authorized only by the channel owner, using their own Google account. It uses YouTube API Services to:

  • upload videos to the owner's own YouTube channel, and
  • read the comments on the owner's own videos in order to count A/B votes.

How data is used and stored

Data obtained through these permissions is used only for those two purposes. The authorization credentials are stored as encrypted secrets in a private code repository belonging to the owner. Comment text is read in order to count votes and is not sold, shared, published, or used for advertising or to train machine learning models.

Sharing

We do not share Google user data with any third party.

Other people's data

The tool has no public users and does not access the accounts or data of anyone other than the channel owner. Viewers who comment on videos are subject to YouTube's own terms and privacy practices.

Revoking access

The owner can revoke the tool's access at any time at myaccount.google.com/permissions. Data can also be deleted by removing the stored credentials.

YouTube API Services

This tool uses YouTube API Services. Please see the YouTube Terms of Service and the Google Privacy Policy.
